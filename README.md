# DSH 动态背景与特效

> 原名：`dsh-dynamic-bg`
> 一句话：**把 DSH 那个灰底色，换成一整屏的图片 / 动图 / 视频，还能调模糊、蒙版、透明度。**

---

## 它解决什么问题

DSH 默认界面是素灰色。看久了累，也没有"自己的空间"的感觉。

**现有的同类插件只支持静态图片**（另有一个只支持 Windows）。
**这个能放视频** —— 循环播放、静音、支持倍速和拖进度条。

---

## 能放什么

| 类型 | 格式 |
|---|---|
| 静态图 | jpg / png / webp / avif / bmp / svg |
| **动图** | gif |
| **视频** | mp4 / webm / mov / m4v |

---

## 能调什么

| 效果 | 范围 | 说明 |
|---|---|---|
| **蒙版强度** | 0–100 | 背景上叠一层半透明，保证任何亮度的图上文字都看得清。深浅主题各一套配色 |
| **背景模糊** | 0–40px | 模糊后自动轻微放大，避免边缘露白 |
| **不透明度** | 0–100 | 背景本身的浓淡 |
| **填充模式** | 铺满 / 完整显示 | 铺满会裁边，完整显示会有留白 |
| **面板半透明** | 主区 / 侧边栏 各自调 | 让内容区透出背景 |
| **一键压暗** | 开关 | 临时把背景压暗，不改上面的参数 |

---

## ★ 为什么它比同类"不容易坏"

DSH 界面的样式里有一堆**带哈希的类名**（形如 `.css-a1b2c3`）。
那些名字**每次版本更新都会变** —— 所以直接改它们的插件，升级后经常突然失效。

**这个插件的做法**：只改 DSH 自己的 **CSS 变量**（`--dsw-*` 那些），
**一个哈希类名都不碰**。⇒ 版本升级后照样能用。

---

## 还带了什么（隐藏功能）

除了背景，代码里还有一整套视觉特效（说明文档还在补）：

- **环境文字特效**：诗词雨 / 二进制雨，7 条泳道防重叠
- **8 套文字配色**：`hacker-green` / `amber` / `magenta` / `cyan` / `white` …
- **输入框聚焦毛玻璃**
- **按会话独立背景**（每个对话可以设不同的背景）

---

## 怎么用

1. 装完重启 `dsh web`，刷新页面
2. 在设置里找到背景设置，填一个**本地文件的绝对路径**（比如 `~/Movies/loop.mp4`）
3. 打开开关，按需调蒙版 / 模糊 / 不透明度

**★ 也可以让 agent 帮你设** —— 它给了三个工具：
`dynamic_bg_set` / `dynamic_bg_get` / `dynamic_bg_off`

---

## 安全边界

它读本地文件，所以做了限制：
- ✅ 只允许媒体扩展名，其它一律 403
- ✅ 只允许绝对路径，相对路径 400
- ✅ 拒绝敏感目录（`/etc`、`/System`、`/dev` 等）
- ✅ 单文件上限 2GB
- ✅ **不写你的任何文件**（只往系统临时目录 `/tmp` 写一份诊断日志，可随时删）
